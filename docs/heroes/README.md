# Heroes: how to make one

Heroes are unique, named champions of a faction, each with its own skin, stats, behaviour, basic attack, skills, an
ultimate charged by energy, passives, out-of-combat abilities at its base, and dialogue lines. Each hero is two files:
`<id>.json` (the hero) and `<id>.png` (its skin).

> Status: the format is final (version 1). The hero system that loads these files is being built next (see
> `docs/ROADMAP.md`); until it ships, `tools/herotool/herotool.py check` is the way to check a file.

## Making a hero with a chatbot

1. Open `hero-prompt.txt` (this folder). It explains the whole format to a chatbot, with an original example.
2. Fill in the box at the very end ("THE HERO I WANT") with the hero you want, then give the chatbot the whole file:
   attach it as a file (it is about 67 KB, often too long to paste), or paste it if your chatbot allows.
3. The chatbot answers with the hero JSON in a code block, the file names, a short skin brief and notes. Save the
   JSON as `<id>.json` (pasting the whole answer into that file also works).
4. Make the skin `<id>.png` from the skin brief in any Minecraft skin editor (64x64, the arm model the JSON names),
   or use a skin you have the right to use.

## Installing

Put `<id>.json` and `<id>.png` side by side in your server's `config/factionclash/heroes/` folder and run
`/fc hero reload` (or restart the server). `/fc hero check <id>` lists every problem with the exact field and what is
allowed; the folder's `_report.txt` has the same lines, ready to paste back into the chatbot ("fix only these lines").
Players need nothing extra: the server sends the skins to them.

Keep your own heroes in your own place (a private repository works well) rather than in this mod's repository: the
mod's repository and its download carry only the mod's original example heroes.

## Checking a file without a server

    python3 tools/herotool/herotool.py check path/to/<id>.json

It runs the same rules as the mod: schema, caps, cooldown floors, allowed words, and prints the computed numbers.

## Files here

- `HERO_FORMAT.md`: the authoritative specification (fields, effect catalogue, caps, validation, implementation map).
- `hero-prompt.txt`: the chatbot prompt, generated by `tools/herotool/build_prompt.py` from
  `tools/herotool/prompt-template.txt`, the catalogue in `herotool.py` and the example; edit those and rebuild.
- `hero.schema.json`: the JSON Schema of a hero file (`herotool.py schema` regenerates it).
- `examples/`: three original example heroes (a frontline protector, a ranged skirmisher, a support).
